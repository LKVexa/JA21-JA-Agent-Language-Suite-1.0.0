# JA21-JA-Agent-Language-Suite-1.0.0

Study bounded plans, governed tools, memory, approvals, and termination with JA21 JA Agent. Its offline suite includes 10,000 technical records, 1,000 .jaa programs, a 22-chapter textbook, and a twelve-week curriculum. Explore capability and replay contracts, diagnostics and source provenance for agent-language research and implementation planning.

The JA21 JA Agent Language Suite is an offline research and teaching collection for bounded agent plans, governed tools, approvals, memory, and termination. Its .jaa examples examine how agent intent relates to capability requirements, policy gates, provenance, and replay contracts. It is designed for educators, language researchers, and developers planning an auditable agent toolchain.

The suite combines 10,000 normalized technical records, 1,000 curated programs, and a 22-chapter textbook. Thirty-two language features are organized across ten proficiency levels and ten validation classes. A twelve-week curriculum, workbook, instructor guide, starter project, catalogs, grammar assets, compiler/runtime specifications, and R12/MCRT contracts provide a complete study path. Offline tools check source hashes, record integrity, declared policy, and package consistency.

The audit identifies disagreements between some source requirements and modeled capability metadata. Current records therefore carry explicit qualifications, and implementers must derive capabilities from actual source before admission. The package supplies no production compiler, scheduler, tool host, or agent runtime. Native tool execution, effective approval enforcement, and prevention of delegated privilege amplification require further implementation and conformance evidence.

## Corpora and audit records

The supplied corpus layout is preserved under `payload/`. The `audit/` directory and [AUDIT_AND_UPGRADES.md](AUDIT_AND_UPGRADES.md) record source coverage, release changes, and evidence boundaries.

Historical source archives and source manifests remain provenance records. Current publication file hashes are listed in `PUBLICATION_SHA256.json`; licensing changes are recorded in `PUBLICATION_LICENSE_LEDGER.json`.
