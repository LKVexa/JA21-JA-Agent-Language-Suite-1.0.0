# Instructor Guide

## Teaching method

Use a three-record pattern for each construct: accepted, expected-fail, and boundary/integration. Require students to trace source → semantics → AST → R12 → MCRT rather than judging source text alone.

## Assessment rubric

- 30% semantic and authority accuracy
- 20% policy and safety reasoning
- 20% evidence/provenance completeness
- 15% diagnostic quality
- 15% publication clarity

## Certification discipline

Freeze the implementation before revealing certification records. Record compiler/runtime versions, manifests, seeds, tool versions, and policy configuration. Do not award credit for outputs that cannot be causally traced.
