# Governance Charter

The suite is governed by five complementary review lenses. SOPHIA protects semantic truth and claim boundaries. CHARLOTTE maintains taxonomy and editorial coherence. LANDON maintains implementable compiler/runtime and safety contracts. Professor maintains teachability and assessment integrity. Podium maintains publication quality and navigation.

Changes to authority, policy, memory, confidence, replay, R12/MCRT evidence, certification classification, or Smithson 8S claim boundaries require explicit review and a versioned release note.
