# Provenance

The suite was derived from `JA_Agent_Language_Coupling_Mechanics_Corpus.jsonl.gz`, a seven-document JSONL wrapper containing the original corpus schema, 10,000-record JSONL corpus, CSV index, manifest, README, samples, and checksum file. The reconstructed source is preserved under `reference_source/` together with the uploaded wrapper.
