# JA Agent Publication System

## Visual language

The suite uses an institutional, air-gap-safe editorial system: short paths, numbered learning tracks, restrained headings, evidence tables, monospaced source blocks, and explicit boundary statements. No network fonts, remote assets, HTML, CSS, or JavaScript are required.

## Information hierarchy

1. Identity and purpose
2. Authority and policy
3. Source and semantic meaning
4. Compiler and runtime evidence
5. Validation status and limitations
6. Learning and certification path

## Podium rule

Every page should help a reader answer: what is this, what may it do, what evidence supports it, what remains uncertain, and where should I go next?
