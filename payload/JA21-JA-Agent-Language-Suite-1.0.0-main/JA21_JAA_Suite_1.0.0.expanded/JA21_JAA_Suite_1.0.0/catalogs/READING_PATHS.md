# Reading Paths

## Agent-language author
Read textbook Chapters 1–15, then browse the feature atlas and positive/integration scripts.

## Compiler engineer
Read Chapters 2, 6–7, and 16–19. Compare accepted and expected-fail records at each semantic boundary.

## Runtime and tool-host engineer
Read Chapters 6–15 and 18–20. Focus on schema validation, capability checks, approvals, sandboxing, replay, budgets, and termination.

## Safety and governance reviewer
Read Chapters 7, 10, 12–15, and 21. Review security, recovery, certification, and policy-escalation scripts.

## Instructor
Use the twelve-week curriculum, textbook chapter sequence, workbook evidence packets, and withheld certification set.
